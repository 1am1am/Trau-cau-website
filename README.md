# Cưới Hỏi Trầu Cau - Website Dịch Vụ Cưới Hỏi Trọn Gói

Website giới thiệu dịch vụ cưới hỏi truyền thống & cao cấp **Trầu Cau Wedding** (cuoihoitraucau.com - 746 Nguyễn Đình Chiểu, Q.3, TP.HCM).

## Cấu trúc dự án
- `index_3.html`: Phiên bản nâng cấp mới nhất với phong cách Hybrid Lookbook, phân khu Kiệt Tác Gia Tộc (hiệu ứng Window Panning / Lens Parallax), Thước Phim Lễ Cưới, và Form Tư Vấn Độc Bản.
- `test/`: Các phiên bản phát triển và giao diện trước đó (`index.html`, `index_2.html`, `main.html`).
